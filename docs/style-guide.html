Trail-Sign Graphic Style Guide

How to design, prompt, and export the icon graphics that sit behind the syllabics on each nêhiyaw MTB trail sign — in a form that reduces cleanly to extrudable, multi-colour 3D shapes. Pairs with the Translation Workbench, the Icon Extruder, and the HueForge Designer.

Why this matters

Every sign is a 3D print: a blank_plaque_thinner.stl plank, raised English + transliteration + protruding syllabics, and — usually — an icon on the plaque that captures the meaning of the trail name (its English sense, its Cree sense, and the place/activity). The icon is the hard part. To turn a generated picture into a printable icon we must be able to:

  1. Separate it into a small number of closed regions (so the Icon Extruder can outline each one).
  2. Map each region to a filament colour from a small palette.
  3. Lift each region to a different height — usually in monotonic steps of the plaque layer thickness — so colours print as stacked layers without filament changes mid-layer being required everywhere.

That goal drives every rule below. The enemy is anything that can't be cleanly thresholded: gradients (except in HueForge mode), soft shadows, anti-aliased fuzz, photographic texture, and thin disconnected specks.

① Screenprint icon default · ~80% of signs

A bold, flat silkscreen / vinyl-decal look: solid shapes, thick keylines, a handful of flat spot colours. This is the workhorse style and the easiest to extrude.

Do

  • Solid flat fills — each colour is one constant value.
  • 2–4 colours max, including the keyline black.
  • Thick, continuous black outlines around every shape.
  • Closed shapes (no open strokes that don't enclose area).
  • One clear subject, centred, with a margin.
  • Pure white #ffffff background.

Don't

  • No gradients, grayscale ramps, or halftone dots.
  • No drop shadows, glows, or soft edges.
  • No photographic texture or noise.
  • No tiny isolated specks or hairline details.
  • No lettering/text baked into the image (the plaque adds text).
  • No frame/border box around the icon.

② HueForge tonal image ~10% of signs

For signs whose meaning is carried by a photographic / scenic / portrait subject (e.g. West Coast Trail, Breathless, Bohemian Maid), a flat stencil loses the magic. Instead generate a continuous-tone image and print it as stacked translucent filament layers using the HueForge Designer. Here the smooth luminance gradient is the height map — darker = thicker stack.

  • Smooth light→dark tonal range; no hard black outlines.
  • Subject fills the frame; simple, uncluttered background.
  • Even, single-direction lighting (avoid blown highlights / crushed blacks).
  • Think in 4–8 tonal bands — that's how many filament swaps you'll realistically use.

Use HueForge mode sparingly (~10%): it costs filament swaps and tuning. Everything else should be a screenprint icon.

③ Embedded printable object ~10% of signs

Following the newest signs (Lovers Lane, Slinky, Bed Springs, Back Breaker) that fuse a real printed object into the plaque, some trail names beg for a literal embedded model — e.g. a mini birdhouse, bottle rocket, print-in-place articulated snake, garden gnome, or paddlewheel boat.

  • The sign still gets a screenprint icon as a backdrop, but its prompt asks for clear negative space in the centre where the object insets.
  • Source the object STL from Printables/Thingiverse, or model it yourself with a small OpenSCAD file.
  • The object is fused onto the plaque by the plaque generator (drop its STL in as the --icon), protruding from the surface.
  • Keep it small, single-piece, and printable without supports where possible (or print-in-place).

Output / extrudability spec (read this before generating)

Regardless of style, request and save the image so the Icon Extruder can reduce it to shapes:

FormatPNG (lossless) or SVGPNG (lossless), 8-bit+
Size1024×1024, square1024×1024, square
Backgroundpure white #ffffffplain, light
Tones2–4 flat, separable colourscontinuous, but ≤ 8 usable bands

Best of allSVG with named, closed paths — the extruder can use the vector shapes directly, skipping edge-detection.—

SVG is ideal. If your image service can emit SVG (or you trace the PNG to SVG), the Icon Extruder will lift each closed path to its own height with perfect edges. PNG is the fallback: it gets posterized to N tones, then each connected region is contoured.

Colour → layer-height mapping

Each separable colour becomes a printed layer at a monotonic multiple of the plaque layer step. Default step = the plaque's print layer height stack (e.g. 0.6 mm groups). Typical convention:

RegionFilamentHeight (steps)Notes
Background planeplaque base0the plaque surface itself
Main fill / silhouetteblack1lowest icon layer
Secondary colourred2e.g. raven's eye/accent
Tertiary colourwhite/other3top highlights
Syllabicscontrasthighestprotrudes in front, set by plaque generator

The Icon Extruder lets you click a region, assign a filament swatch, and set its layer index; it then extrudes a manifold STL with each region at its mapped height. Keep heights monotonic (taller = printed later / on top) so the AMS/manual swaps go in one direction.

End-to-end workflow

  1. Pick the concept in the Workbench — each trail has a suggested concept, type badge, and an editable prompt.
  2. Generate the image (button calls your configured image API) or paste your own. Aim for the output spec above; export SVG if you can.
  3. Reduce to shapes in the Icon Extruder: posterize / load SVG → review detected regions.
  4. Paint with filament: click each closed region, assign a palette colour, set its layer height.
  5. Export the icon STL (each region at its mapped height; manifold, ready to fuse).
  6. Generate the plaque with tools/plaque_gen/plaque_gen.py: pass English + transliteration + syllabics and the icon STL; it writes a .scad and renders a draft .stl with text auto-fit (multi-line, centred) and syllabics protruding in front.
  7. Print, swapping filament at the layer heights you assigned.
