nêhiyaw Trail Names — ᓀᐦᐃᔭᐤ Translation Workbench

Edmonton MTB trails, default-ordered by Trailforks ride check-ins (most-ridden first). This is a non-destructive merge of three source lists — ride check-ins, pageviews, and Trailforks global ranking — so each trail shows all three metrics, with a blank (—) where a trail appears on only some lists. Each name has up to three candidate Plains Cree (nêhiyawêwin) renderings — syllabics + transliteration — with reasoning, word components, and notes on innuendo / second meanings. These are draft AI guesses for review: tick the checkbox once a translation has been vetted by a speaker (ticked rows grey out and persist across reloads). Click any column header to re-sort; click show ▾ to expand suggestions.

Cree orthography: Standard Roman Orthography (SRO) with Western Cree syllabics (ᓯᓚᐯᐗ). Proper nouns / pop-culture names (Pete, Ewok, Yoda, Messier) are spelled phonetically into syllabics where no semantic translation exists; otherwise meaning-based translations are given. Distances/elevation parsed from the source lists. Check-ins = recorded ride check-ins (higher = more ridden). Pageviews = Trailforks page-view count (higher = more viewed). TF global rank = the value from the global-ranking list (lower = higher-ranked). Trails not on a given list show — for that metric. Overall rank = average of ordinal ranks for those three metrics (1 = best); a trail missing a metric is scored as rank n+1 for that metric (n = number of trails with a value), tied with all other trails missing that metric. The leading # column is just the current display position.
