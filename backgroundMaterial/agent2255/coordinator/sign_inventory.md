## How to read this file

For each of the 19 target signs:
- `id` — catalogue.json `id` (kebab-case; this is what the renderer takes on the CLI).
- `folder` — actual repo + docs folder slug. **Some are camelCase / use diacritics**, follow them verbatim.
- `catalogue creeName` / `creeSyllabics` — current catalogue values (may be wrong; see ✱ flags).
- `wall-sign read` — what coordinator visually read from `allSigns.jpg` for this plaque. **Trust the carved plaque first.**
- `root images` — design files under repo root `{folder}/` (PNG/JPG).
- `docs/{folder}/` — public folder (`index.html` is auto-regenerated by renderer; keep STLs untouched).
- `docs/assets/{folder}/` — currently empty for **every** target. Each manager either copies the existing root design image here, OR crops from `allSigns.jpg`.

`allSigns.jpg` is 8160 × 6144 px (RGB). A downscaled preview is at `/tmp/allSigns_preview.jpg` (1600 × 1205).
Coordinate planning is easier off the preview, but **crop from the original `allSigns.jpg`** for final pixel quality.

## Photo wiring strategy (mandatory per pilot lesson)

Every manager MUST set `pageContent.photo.src` on every fragment, using ONE of these three options in order of preference:

1. **Wire an existing root design image into `docs/assets/`** — for most signs we already have a design PNG at `{folder}/{name}.png`. Copy it into `docs/assets/{folder}/{name}.png` (renaming spaces / odd chars as needed) and set `photo.src = "../assets/{folder}/{name}.png"`. This is the cleanest path.
2. **Crop the plaque from `allSigns.jpg`** — when no root design image exists (or it is unrepresentative, e.g. `bed-springs`, `lovers-lane`, `slinky`, `deliverance`). Crop with PIL and save to `docs/assets/{folder}/sign_render.png`. Approximate crop coordinates (in the FULL 8160×6144 original, not the preview) — use these as starting boxes and adjust by visually verifying the saved crop:
   - `bed-springs`: roughly (2750, 4400) → (3550, 5400) in original coords (lower-mid section).
   - `lovers-lane`: roughly (1900, 2900) → (2600, 4200) (the upper heart) or (2400, 4400) → (3300, 5500) (the lower heart).
   - `deliverance`: roughly (4700, 3300) → (5700, 4350) (banjo + flames, right of Purgatory in row 3).
   - `slinky`: the entire red coil is roughly (900, 200) → (2400, 5000); a tight upper-coil crop around (1300, 100) → (2300, 1100) reads better as a "sign".
3. **Last resort: empty `photo.src`** — leave `photo.src = ""` and add a `notes` entry. Avoid this — the pilot identified photo wiring as the #1 miss.

When in doubt, READ the crop you just wrote back as an image (every manager has `Read` access to image files) and adjust the box if you got the wrong plaque.
